# Shreyash Katiyar — .NET Developer Portfolio

A personal portfolio website showcasing my technical skills, professional experience, education, and projects as a .NET Developer.

## About the Project

This portfolio is designed to present my background in .NET development and demonstrate my experience building web applications and RESTful APIs. It provides an overview of my technical skills, projects, education, and contact information.

## Features

- Professional portfolio homepage
- About Me section
- Technical Skills section
- Professional Experience section
- Projects showcase with GitHub repository links
- Education and Qualifications section
- Contact information and social media links
- Resume viewing option
- Contact form with email integration through the user's email application
- Responsive layout for desktop, tablet, and mobile devices

## Getting Started

### Prerequisites

- A web browser
- Visual Studio Code (recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Shreyashmoon123/Portfolio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Portfolio
   ```

3. Open the folder in Visual Studio Code:

   ```bash
   code .
   ```

4. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
